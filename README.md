## À propos de ce projet

Ce projet de régression vise à prédire la production électrique future des micro-turbines à gaz à partir de données historiques.  
L’objectif est d’optimiser l’efficacité énergétique en anticipant la production et en facilitant la prise de décision opérationnelle.

Les étapes principales réalisées sont :  

- 🔄 **Prétraitement des données** incluant la normalisation et le nettoyage,  
- 🔍 **Analyse exploratoire (EDA)** avec des visualisations riches pour mieux comprendre les tendances,  
- 📈 **Construction et entraînement** de modèles de régression (régression linéaire, Random Forest, CatBoost),  
- 🖥️ **Déploiement interactif** via une application Streamlit pour la visualisation des résultats.
